6. ShopSphere – Multi-Vendor E-Commerce Marketplace
Tech Stack: MERN (MongoDB, Express.js, React, Node.js)  •  AI-Enabled Capstone
Description
Create a marketplace where multiple independent sellers can list products and customers can purchase from different vendors. The system must support catalog management, inventory, carts, orders, returns, seller settlements, reviews, coupons, and administrative moderation. AI features can improve product discovery and seller productivity.
Roles and Responsibilities
Role	Responsibilities
Platform Admin	Approve sellers, moderate products, manage categories, users, coupons, disputes, and platform reports.
Seller	Manage store profile, products, inventory, pricing, orders, returns, and seller analytics.
Customer	Browse products, manage cart/wishlist, place orders, review purchases, and request returns.
Support Agent	Handle customer issues, order disputes, refunds, and support tickets.
Delivery Partner	View assigned deliveries and update shipment status.
Features
	Authentication with customer, seller, support, delivery, and admin authorization.
	CRUD for sellers, stores, products, categories, variants, inventory, coupons, orders, reviews, returns, and support tickets.
	Multi-vendor cart and order splitting while preserving a single customer checkout experience.
	Inventory reservation and stock updates across order lifecycle states.
	Order state machine: placed, confirmed, packed, shipped, delivered, cancelled, returned, refunded.
	Seller dashboards for revenue, orders, inventory, and product performance.
	AI integration: generate product descriptions and key selling points from structured product attributes.
	AI integration: semantic product search and recommendation based on user intent and browsing behavior.
	Review moderation, wishlist, notifications, advanced filtering, pagination, and audit logs.
Capstone expectation: Implement the project as a complete MERN application with REST APIs, MongoDB data modeling, React routing/state management, server-side validation, error handling, secure authorization, responsive UI, and meaningful test data.
